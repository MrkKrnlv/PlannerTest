# Планер

Личный планер, который живёт в браузере, ставится на телефон как приложение, открывается как Telegram Mini App и синхронизируется между всеми устройствами. Задачи можно надиктовать боту голосом: n8n расшифрует, AI-агент разложит по дням и добавит в планер.

Работает бесплатно в рамках free-тарифа Cloudflare (Workers со статикой и D1).

## Что умеет

Навигация: **Сегодня**, **Планы**, **«+»**, **Рост**, **Ещё**. Всё новое добавляется через «+»: задача, привычка, заметка, таймер.

**Сегодня**
- Карточка «Сейчас»: текущая задача, ближайшая или что взять в свободное окно, с кнопками «Фокус» и «Готово».
- Блоки задач по времени: высота зависит от длительности, видны свободные окна и линия «сейчас». Ниже задачи без времени, хвосты с прошлых дней, привычки на день.
- **Спланировать день**: шкалы «Время» и «Голова», что перенести на завтра при перегрузе, предпросмотр автоплана. Главное и глубокая работа уходят в пик энергии, мелочи после него, обед свободен, расстановку можно отменить.
- **Завершить день**: три шага. Разобрать несделанное (сделано, завтра, во входящие, удалить), отметить настроение и энергию, записать, что было хорошего.
- Быстрый ввод: `созвон с клиентом 1.5ч в 16:00 завтра #работа !`. Понимает `завтра`, дни недели, `утром/днём/вечером`, `!` (важно), `!!` (главное на день), `~` (не срочно).
- Поиск по задачам и заметкам (`Ctrl+K`).

**Задачи**
- Повторы: каждый день, по будням, по дням недели, каждый месяц. Следующая появляется, когда отмечаешь текущую.
- Подзадачи-чеклист.
- Главное на день, глубокая работа, сфера, приоритет, заметка, фокус-таймер прямо из задачи.

**Планы**
- **Входящие**: задачи без даты, разбор в один тап (сегодня, завтра, дата).
- **Неделя**: баланс по сферам и метка «лёгкий день».
- **Месяц**: загрузка, очки (10, 25, 30 за задачу по размеру, 40 за главную на день), серия дней подряд, рекорды по дням недели.

**Рост**
- Привычки: дни недели, серии, процент за месяц, сетка за 14 дней, напоминания.
- Сферы жизни: недельная цель в часах, прогресс, тихие подсказки про забытые сферы.
- Цикл 12 недель: цели, еженедельные шаги, процент по неделям против 85%.

**Ещё**
- Таймеры: фокус 25/50 и параллельные побочные таймеры, переживают перезагрузку.
- Заметки с поиском (`Ctrl+J`).
- **Экспорт месяца для Claude**: кнопка копирует готовый запрос на разбор и все данные месяца одним блоком, можно скачать JSON.
- Настройки дня: рабочие часы, пик энергии, обед, нормы.
- Знакомство с разделами (показывается при первом входе).

**Везде**
- Синхронизация между устройствами, работа без сети, PWA.
- Telegram Mini App с входом без пароля, темой и хаптиками.
- Дизайн liquid glass: матовые панели поверх мягкого фона. Blur только на навигации, шапках и шторках, строки списков без него, чтобы не тормозило в слабых WebView.

## Архитектура

```
 Браузер / PWA / Mini App                Cloudflare                       n8n
 ┌──────────────────────┐   Bearer   ┌──────────────────────┐  service key  ┌──────────────────┐
 │ React + Zustand      │──────────▶│ Worker /api + статика│◀──────────────│ Telegram Trigger │
 │ localStorage (копия) │◀──────────│ D1 (SQLite)          │               │ Whisper → Agent  │
 └──────────────────────┘  дельта    └──────────────────────┘               └──────────────────┘
```

| Слой | Что |
|---|---|
| Фронт | React 19, Zustand 5 (persist в localStorage), Vite 8, чистый CSS, шрифт Golos Text (self-hosted) |
| API | Cloudflare Worker: `server/worker.js` отдаёт `/api/*`, остальное — статика из `dist/` |
| База | Cloudflare D1. Схема создаётся сама при первом запросе (`server/schema.js`) |
| Офлайн | `public/sw.js`, `public/manifest.webmanifest` |

### Данные

| Таблица | Что хранит |
|---|---|
| `tasks` | задачи построчно, включая повтор и подзадачи (их же пишет n8n) |
| `items` | документы `kind + JSON`: привычки и отметки, итоги дней, сферы, цикл 12 недель, цели и шаги, настройки дня |
| `users` | пользователь Telegram и его ключ |

Таймеры живут только на устройстве.

### Как устроен синк

Одинаково для задач и документов:

1. Каждая правка поднимает у записи `updated_at` и помечает её грязной.
2. **Push:** грязные записи уходят целиком (`POST /api/tasks/sync`, `POST /api/items/sync`). Сервер применяет правку, только если она новее сохранённой (last-write-wins по записи).
3. **Pull:** клиент забирает всё, что изменилось после его ревизии (`GET …?since=<rev>`). `rev` — серверный счётчик, а не время клиента, поэтому неточные часы на телефоне ничего не ломают.
4. Удаление — это надгробие `deleted = 1`, оно синкается как обычная правка, и запись не «воскресает».
5. Отметки привычек и шагов имеют детерминированные id (`hl:<привычка>:<дата>`), поэтому отметки с двух устройств сливаются, а не дублируются.

Почему D1, а не KV: KV eventually consistent (запись расходится до минуты) и на бесплатном тарифе даёт 1000 записей в сутки. D1 — это SQLite с транзакциями, плюс n8n может добавлять отдельные задачи, не трогая остальные.

### Авторизация

| Кто | Как |
|---|---|
| Mini App | `initData` от Telegram → `POST /api/auth/telegram` проверяет подпись токеном бота и выдаёт персональный ключ |
| Браузер / PWA | Тот же ключ: Mini App → Ещё → Настройки → «Ключ для браузера» |
| n8n | `X-Service-Key` + `X-Telegram-User-Id`: действует от имени конкретного пользователя Telegram |

## Локальный запуск

```bash
npm install
cp .dev.vars.example .dev.vars
npm run build
npm run dev:api      # Worker: API и собранный фронт на http://localhost:8788
npm run dev          # во втором терминале: фронт с автообновлением на http://localhost:5173
```

На экране входа введи `dev`.

Проверки:
- `npm run test:api` — синк, LWW, удаления, документы, n8n, изоляция пользователей;
- `npm run test:logic` — автоплан, нагрузка, привычки, 12 недель, очки, повторы, экспорт, разбор ввода.

## Деплой

Через дашборд Cloudflare:

1. **База.** Storage & databases → D1 → Create, имя `planner`. Её id вписать в `wrangler.toml` → `database_id`. Таблицы создадутся сами.
2. **Worker.** Workers & Pages → Create → Import a repository → этот репо. Build command `npm run build`, Deploy command `npx wrangler deploy`. Имя Worker должно совпадать с `name` в `wrangler.toml`.
3. **Секреты.** Settings → Variables and Secrets → Add, тип **Secret**: `BOT_TOKEN`, `SERVICE_KEY`. Именно Secret: обычные переменные, которых нет в `wrangler.toml`, стираются при следующем деплое из Git.
4. Каждый пуш в `main` деплоится сам.

Или из консоли:

```bash
npx wrangler login
npx wrangler d1 create planner          # id -> wrangler.toml
npx wrangler secret put BOT_TOKEN
npx wrangler secret put SERVICE_KEY     # openssl rand -hex 32
npm run deploy
```

## Бот и Mini App

1. `@BotFather` → `/newbot` → получишь токен (его же в `BOT_TOKEN`).
2. `/mybots` → бот → Bot Settings → Mini Apps → Menu Button → URL приложения с `https://`, текст «Планер».
3. Открой бота, нажми «Планер». Вход произойдёт сам.

## Голосовой ввод через n8n

Файл `n8n/voice-to-planner.json` → в n8n: Import from File.

```
Telegram Trigger → голосовое? ─да─→ скачать → Whisper ─┐
                              └нет──────────────────────┴→ текст → задачи на 7 дней → AI Agent → есть задачи? → POST /api/tasks → ответ в Telegram
```

По умолчанию ИИ-часть на **Groq**: Whisper Large V3 Turbo для голоса и `openai/gpt-oss-120b` для агента. Бесплатного уровня Groq хватает на личное использование, а платно это доли цента за голосовое.

После импорта:

1. **Credentials.**
   - Telegram API (тот же токен бота).
   - **Groq**: ключ с console.groq.com, один на расшифровку и агента.
   - Header Auth с именем `Planner service key`: Name `x-service-key`, Value — твой `SERVICE_KEY`.
2. Адрес планера в узлах «Задачи на неделю» и «Добавить в планер» — `https://plannertest.marksohokornilov.workers.dev`. Если у тебя другой, замени.
3. Часовой пояс в выражениях — `Europe/Moscow`.
4. Активируй воркфлоу. Telegram Trigger требует, чтобы n8n был доступен по HTTPS.

Провайдер видит IP сервера n8n. Если сервер в РФ, проверь доступность Groq одним тестовым запросом.

Чтобы вернуться на OpenAI:
- в узле расшифровки поменяй URL на `https://api.openai.com/v1/audio/transcriptions`, модель на `whisper-1`, credential на OpenAI;
- Groq Chat Model замени на OpenAI Chat Model.

**Что делает агент:**
- видит уже запланированное на неделю и не ставит задачи на занятое время;
- оценивает длительность;
- помечает глубокую работу и главное на день;
- дробит размытые задачи;
- переносит лишнее, если день перегружен.

Логика в системном промпте узла AI Agent. Пересобрать воркфлоу: `python3 scripts/build-n8n-workflow.py`.

У одного бота может быть только один вебхук, и его держит n8n. Mini App вебхук не нужен, конфликта нет.

## Ограничения

- LWW работает по записи целиком: если одну задачу одновременно правят на двух устройствах, победит более поздняя правка.
- Надгробия удалённых записей не чистятся. Для личного планера это килобайты.
- Ключ браузера бессрочный, ротации пока нет.
- Напоминания привычек срабатывают, пока планер открыт. Внутри Telegram системных уведомлений нет.
- Из РФ `*.workers.dev` у части провайдеров открывается медленно или нестабильно. Проверь до публикации видео. При проблемах привяжи свой домен.
